非结构化Excel解析

一、功能概述

读取一个或多个非结构化Excel内容，转换为结构化数据。

三、操作步骤

1、界面元素输入或选择：
配置文件选择：选择文件所在的目录。
Excel第几个页签：读取Excel中第几个页签的数据，默认为第一个。
Excel类型：包括xls、xlsx两种类型。
移除所有列为空数据：复选框，当选中时会删除所有列为空数据的列，减少多余的列。
6、点击【读取】：成功后，会提示相关信息。

四、逻辑与业务规则

本功能的结构化与非结构化数据解释：
结构化数据：是指包含列和行的数据，即Excel一个页签中，数据包括M列N行数据。
非结构化数据：是指一个页签只是一行数据，其所有的单元格都作为一列的数据。
