点击复制字符

一、功能概述

在工作中，我们经常需要输入一些服务器地址、用户名和密码等，或者经常打开一些工作目录。该功能就是为了快速复制字符或打开目录使用。
注：为了安全起见，重要的密码请配置为加密，加载文件过程中会自动加密保存，即明文的密码会变为加密后的字符，但不影响复制！！

三、操作步骤

1、【模板下载】：下载后维护相关信息。
strings：根节点；属性包括：max：group的默认每行项目数；子节点包括：params、global、tap。
tap：页签，为2级节点；属性包括：name：页签名称。子节点包括：group。
params：全局参数集合，为2级节点，无属性；子节点包括：param。
param：参数，为3级节点；属性包括：key：键（不区分大小写）、value：值、remark：备注。用于string节点中text属性引用（格式：#key#）。
global：全局组，为2级节点，无属性，子节点包括：group。建议最多配置1至2个group子节点。
group：分组，为3级节点，子节点包括：string。属性包括：
  text：组名。没选中【流式布局】时，才显示。
  fontColor：组名的颜色，默认黑色。没选中【流式布局】时，才显示。
  max：确定本分组的每行项目数，当不指定时则取根节点配置的max属性。
  itemFontColor：组内子项显示的标签颜色，默认黑色。

string：复制项，为4级节点。无子节点；其属性包括：
  type：text文本，用于复制字符的；path路径，可复制或打开；file是文件，可读取文件内容来复制，当文件不存在时会显示黄色。
  ctrol：TextBox是一般文本框；RichTextBox是富文件框，针对type为file的配置。
  label：标签，显示的复制项名称。
  text：实际拷贝的内容。支持全局配置参数、内置参数的字符替换，如【#yyyyMMdd#】表示替换为当前日期字符，适用场景如当天备份目录名。如果要输出实际的#，请使用{{@JH@}}代替。
  needEncrypt：是否需要加密：0-否，1-是
  hadEncrypt：是否已加密：0-否，1-是。当需要加密时，这里改为0，并且【text】属性要改为明文，在加载XML文件时，会自动加密并保存文件。
  pwdchar：设置密码掩码字符，如复制的是密码，请设置其值为*。
  tip：按钮的提示信息。
  pathAbs：读取文本文件的绝对路径，针对type为file的配置。
  pathRel：读取文本文件的相对当前选择的配置文件所在目录的路径，针对type为file的配置。
  fontColor：标签的颜色，默认黑色，支持颜色名称、16进制、RPG三种表示方式。
4、输入或选择相关信息：
首次打开功能，我们需要选择填好的模板文件，选择后就会自动生成可复制或打开的界面元素。
【配置文件】：下拉框，我们可以在选择填好的模板文件后，输入【模板名】，点击【保存】，下次即可以下拉框中快速选择加载。
【删除】：如我们希望之前保存过的配置文件不出现下拉框中时，可以选择该项后，点击【删除】，即可从下拉框中移除该项。
【流式布局】：当选中时，每行显示的项将尽可能的多。
【重新加载】：重新根据配置文件加载内容：这在我们修改文件内容后，可以在不重新打开页面的情况下，重新加载内容。

四、逻辑与业务规则

加密配置：
string节点增加属性配置：needEncrypt="1" hadEncrypt="0"，即可触发加密。
如string节点的needEncrypt="1" hadEncrypt="1"，表示该节点已加密，不会再次触发加密。
内置参数
目前只有内置日期参数（不区分大小写），包括：yyyyMMdd、yyyy-MM-dd、yyyy-MM、yyyyMM、yyyyMMddHHmiss、yyyyMMddHHmi、yyyy。
【strings】的【max】配置：
当group中没有指定max属性值时，会使用【strings】的【max】全局配置。
