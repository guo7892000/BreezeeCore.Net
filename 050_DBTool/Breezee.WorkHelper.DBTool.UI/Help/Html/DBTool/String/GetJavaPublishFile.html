获取Java的class文件

一、功能概述

针对修改过的源码，获取其对应的class文件，方便于替换发布。
注：每次修改源码后，记得要重新编译后再获取，否则得到的class文件可能不是最新的！！

三、操作步骤

【公共】
1、【配置选择】：可以选择以前输入的配置信息。
2、【覆盖类型】：包括！
覆盖：任何日期的复制，文件都会直接复制到【复制到目录】下，并覆盖之前日期复制的文件。
覆盖当天：在【复制到目录】下创建一个当天日期目录，然后复制的文件放该目录下。当天多次复制，都会使用该目录，并覆盖之前的文件。
每次新增：每次生成，都在【复制到目录】下创建一个当天日期-时分秒目录，文件放入其中。当天多次复制，每次都放入不同目录。
【复制配置】页签
1、【源代码目录】：输入或选择要源码所在的目录，即src的上一级目录！
2、【复制源目录】：编译后的项目最新class目录。注：如项目是JSP那种包括页面的项目，并且使用JBOSS编译，那么其路径需要指定到JBOSS编译的War包下，如D:\jboss-as-7.1.1\standalone\deployments\Test.war。
如果是不包含页面的项目，可以直接使用项目路径下的Target目录，如：D:\TestInf\target\classes。
3、【复制到目录】：将跟代码变更相关的class文件，复制到指定的目录。
4、【配置名称】：必填项，可以保存复制所需配置项，以方便下次使用。
5、【源代码、复制源目录、复制到目录对照关系配置】：根据修改过的源码文件，找到编译后的路径，复制对应文件到最终目录。包括以下列：
选择：只针对选中的配置来匹配。通常不用项会删除，所以该列不重要。
从源码复制：可针对JSP、JS文件选中，即从源码目录中复制文件。
代码目录：必填，针对源码中对应目录的配置。
Class目录：非必填，如果class后续目录跟源码一致时，可不填；不一致时才需要指定。
复制到目录：非必填，如果需要指定生成到一个统一目录中时，可以输入。
注：网格支持右键功能，包括：
粘贴：可以从Excel中复制三列数据（按【从源码复制、Class目录、复制到目录】顺序），并粘贴到网格中
删除：删除选择行
清空：清除网格所有行。
【变更的源代码文件】页签
包括手工粘贴、查询获取两种录入方式。包括一些公共选项：
生成打开目录：复选框，选中时获取完成后，会自动打开目录
一、手工粘贴：
支持从Excel中复制一列数据，然后按crtl + v键（或右击网格，再点粘贴），可以把数据加到网格中。
粘贴累加：复选框，选中时复制的内容追加在列后面。
war包名小写：复选框，选中时生成的根目录名为小写（某项目特殊需求）。
二、查询获取：注只有签入git中文件才能获取得到。
1、排除目录或文件选项：
【排除目录】：排除相对于【代码目录】的相对路径为【排除目录】文本框内输入的子目录。
【排除文件】：排除相对于【代码目录】的相对路径为【排除文件】文本框内输入的文件。
从【x】天前开始获取时：选中时，会根据输入的值来自动修改开始时间。
【结束时间为当前时间】：选中时点获取，会从开始时间到当前时间前签入的所有文件
【排除后缀】：支持排除指定后缀的文件清单。
【保存结束时间】、【从上次结束时间开始】：当获取时选中了【保存结束时间】，才可选中【从上次结束时间开始】，会自动修改开始时间为上次获取的时间。
2、【修改时间】：我们可以选择开始和结束时间，然后点击【获取】，会将这段时间内修改的代码文件加入到【变化文件录入】网格中。
3、点击【复制发布文件】：将会异步复制文件到指定目录，并保存配置。
复制成功后，会在【生成结果】中显示本次复制的文件清单。

四、逻辑与业务规则

注意点：支持逗号（中英文）、分号（中英文）、冒号（中文）、竖线（英文）分隔的多个排除项配置！另外：会过滤以.开头的文件或文件夹。
所有的文件路径都从src目录开始。
