## VS CODE
### 概述
Visual Studio Code（简称VS Code）是微软公司于2015年4月30日发布的跨平台源代码编辑器，支持Windows、Linux和macOS系统。
内置JavaScript、TypeScript及Node.js支持，通过扩展生态系统覆盖C、C#、Java等编程语言及.NET、Unity等开发环境，集成语法高亮、Git版本控制和可定制快捷键功能。
支持了如下38种语言或文件：F#、HandleBars、Markdown、Python、Java、PHP、Haxe、Ruby、Sass、Rust、PowerShell、Groovy、R、Makefile、HTML、JSON、TypeScript、Batch、
Visual Basic、Swift、Less、SQL、XML、Lua、Go、C++、Ini、Razor、Clojure、C#、Objective-C、CSS、JavaScript、Perl、Coffee Script、Dockerfile、Dart、C、Kotlin。
### VS CODE中执行npm -v，报错，但在Windows的命令行是能正常运行的
VS CODE默认PowerShell，修改为Command Prompt即可，方法：文件->首选项->设置->搜索终端->终端集成->默认配置文件->选择Command Prompt。
