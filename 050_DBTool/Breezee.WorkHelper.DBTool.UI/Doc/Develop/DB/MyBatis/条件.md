### 在 MyBatis 中，判断字符串相等需要使用 .equals() 方法，并且要注意空值处理
```
方式一：使用 toString()	
<if test='status == "active".toString()'>	
    AND status = 'active'	
</if>	

方式二：使用双引号包裹（推荐）	
<if test='status == "active"'>	
    AND status = 'active'	
</if>	

方式三：使用单引号包裹
<if test="status == 'active'">
    AND status = 'active'
</if>

```
### 判断非空或为空
```
<!-- 既不为 null 也不为空字符串 -->	
<if test="status != null and status != ''">	
 AND status = #{status}	
</if>	
	
<!-- 为 null 或空字符串 -->	
<if test="status == null or status == ''">	
 AND (status IS NULL OR status = '')	
</if>	
```
