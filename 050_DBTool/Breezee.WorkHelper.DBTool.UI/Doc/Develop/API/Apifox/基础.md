## Apifox
Apifox是一款API设计、开发、测试一体化协作平台，由广州睿狐科技有限公司开发，主要提供API文档管理、调试、数据Mock和自动化测试等功能。该平台集成了API设计、文档、调试、Mock和测试等多种能力，
支持HTTP/2、WebSocket、gRPC、Dubbo、GraphQL等多种协议，并提供私有化部署选项。该平台亦支持AI生成测试用例、MCP调试等功能。
### 网站介绍
官网：https://apifox.com/   
Apifox是 API 文档、API 调试、API Mock、API 自动化测试一体化协作平台，更先进的 API 设计/开发/测试工具，定位 Postman + Swagger + Mock + JMeter。  
只要定义好 API 文档，API 调试、API Mock、API 自动化测试即可直接使用，无需再次定义。API 文档和 API 开发调试使用同一个工具，API 调试完成后即可保证和 API 文档定义完全一致。  
登录后，可以保存在线的API列表，也支持桌面版。在Chrome浏览器中发送请求是，需要安装插件，在测试时按要求操作即可。
### 网站定位
是API 文档、API 调试、API Mock、API 自动化测试一体化协作平台。  
### 网站功能
1、接口支持“用例管理”；  
2、“数据模型”定义、引用；  
3、调试时“自动校验”数据结构；  
4、“可视化”设置断言；  
5、“可视化”设置提取变量；  
6、支持数据库操作；  
7、“零配置”Mock 出非常人性化的数据；  
8、生成在线接口文档；  
9、代码自动生成；  
10、导入、导出。
