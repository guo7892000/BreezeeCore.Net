## 请求

### 前后端请求示例
***前端对应的配置***
```
$.ajax({
    type: 'post',
    url: getWebUrl(contxtpath, 'auth/checkLoginUser.action?t=' + new Date().getTime()),
    contentType: "application/json;charset=UTF-8",
    data: JSON.stringify({"operId": username}),
    dataType: 'text',  // 期望接收纯文本
    success: function(response){
        // 注意：这里 response 直接就是字符串，不是 JSON 对象
        if (response === username) {
            // 登录成功
        } else {
            // 登录失败，response 可能是 "error" 或其他提示
        }
    }
});
```
***常见的 dataType 取值：***  
值	    说明  
json	返回 JSON 数据，jQuery 自动解析为 JS 对象  
xml	    返回 XML 文档  
html	返回 HTML 文本
text	返回纯文本，不解析  
script	返回 JavaScript 代码并自动执行  
jsonp	跨域 JSONP 请求  
  
当 dataType: 'text' 时，表示前端期望接收纯文本格式的响应，后端 Controller 的配置非常简单，主要有以下几种方式：  
方式一：直接返回字符串（最常用）  
```
@Controller
public class AuthController {

    @RequestMapping(value = "/auth/checkLoginUser", method = RequestMethod.POST)
    @ResponseBody
    public String checkLoginUser(@RequestBody Map<String, String> request) {
        String operId = request.get("operId");
        
        // 直接返回字符串，Spring 会默认以 text/plain 格式输出
        if (isValidUser(operId)) {
            return operId;  // 返回用户名
        } else {
            return "error"; // 返回错误标识
        }
    }
}
```
关键点：  
使用 @ResponseBody 注解  
方法返回值类型为 String  
Spring 默认的 StringHttpMessageConverter 会以 text/plain;charset=UTF-8 格式输出  

方式二：显式指定 produces（推荐）  
```
@Controller
public class AuthController {

    @RequestMapping(
        value = "/auth/checkLoginUser", 
        method = RequestMethod.POST,
        produces = "text/plain;charset=UTF-8"  // 明确指定返回格式
    )
    @ResponseBody
    public String checkLoginUser(@RequestBody Map<String, String> request) {
        String operId = request.get("operId");
        
        if (isValidUser(operId)) {
            return operId;
        } else {
            return "invalid_user";
        }
    }
}
```
produces 的作用：  
告诉 Spring 这个方法只处理能接受 text/plain 格式的请求  
响应头中的 Content-Type 会被设置为 text/plain;charset=UTF-8  

方式三：使用 ResponseEntity 更灵活  
```
@Controller
public class AuthController {

    @RequestMapping(value = "/auth/checkLoginUser", method = RequestMethod.POST)
    @ResponseBody
    public ResponseEntity<String> checkLoginUser(@RequestBody Map<String, String> request) {
        String operId = request.get("operId");
        
        if (isValidUser(operId)) {
            // 可以自定义状态码和响应头
            return ResponseEntity
                .ok()
                .contentType(MediaType.TEXT_PLAIN)
                .body(operId);
        } else {
            return ResponseEntity
                .status(HttpStatus.UNAUTHORIZED)
                .contentType(MediaType.TEXT_PLAIN)
                .body("invalid_user");
        }
    }
}
```
方式四：如果使用 @RestController  
```
@RestController  // 等价于 @Controller + @ResponseBody
public class AuthController {

    @PostMapping(value = "/auth/checkLoginUser", produces = "text/plain;charset=UTF-8")
    public String checkLoginUser(@RequestBody Map<String, String> request) {
        String operId = request.get("operId");
        return isValidUser(operId) ? operId : "error";
    }
}
```
