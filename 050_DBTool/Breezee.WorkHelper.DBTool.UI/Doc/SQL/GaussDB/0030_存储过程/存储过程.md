### 关于存储过程中有【\】正则字符的问题
```
P_NewCncCode_Add，有空转一下这个存储过程，然后再修改看看。这个不知道为什么生成后，查看DLL，最前面会多一个双引号，然后\会变为两个，再次修改执行会变为4个\。
原因：
出现反斜杠翻倍现象，核心原因在于转义字符（Escape Character）的处理机制。在不同的上下文中，反斜杠的含义不同：
在SQL字符串字面量中，\n代表换行符，\\才代表一个普通的反斜杠字符。
当DBeaver通过JDBC从数据库获取存储过程定义时，为了让获取到的字符串在SQL中是合法且完整的，它会依据规则对特殊字符进行转义，这就可能导致原本是单个的反斜杠，在显示时变成了两个。
解决方案：目前最佳的临时处理方式是，在获取到存储过程的DDL（定义语句）后，手动将翻倍的反斜杠（\\）替换回单个反斜杠（\），然后再进行修改和保存。

```
