### 函数基础
### 分拆字符函数  
```
Function F_GetStrConvertCol(i_str varchar, --被拆分的字符				
							i_delim varchar := ',' --拆分的隔离元素				
							) return SETOF text is				
	v_cursor SYS_REFCURSOR;				
	v_sql VARCHAR2(4000);				
BEGIN				
	RETURN QUERY				
	Select unnest as column_value From unnest(string_to_array(i_str,i_delim));				
End F_GetStrConvertCol;				

```
### 如没有gen_random_uuid，可手工创建一个
```
CREATE OR REPLACE FUNCTION public.gen_random_uuid()
 RETURNS character varying
 LANGUAGE sql
 NOT FENCED NOT SHIPPABLE
AS $function$
    SELECT replace(md5(random()::text || clock_timestamp()::text)::text,'-','');
$function$;
;
```
