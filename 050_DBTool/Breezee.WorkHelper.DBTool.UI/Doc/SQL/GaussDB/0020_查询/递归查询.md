### 递归
所谓递归,简单点来说,就是一个函数直接或间接调用自身的一种方法,它通常把一个大型复杂的问题层层转化为一个与原问题相似的规模较小的问题来求解。
#### 递归查询
```
WITH RECURSIVE P_FETURE AS (
    /*初始化查询，选择直接下属*/
    SELECT node_id, node_pid 
    FROM EBOM_V_FETURE_ALL
    WHERE node_pid = '01384_JF' 
    UNION ALL
    /*递归部分，选择所有间接下属*/
    SELECT e.node_id, e.node_pid
    FROM EBOM_V_FETURE_ALL e
    JOIN P_FETURE s ON e.NODE_PID = s.node_id
)
SELECT * 
FROM ebom.EBOM_V_FETURE_ALL t 
join P_FETURE p 
	on t.node_id = p.node_id
WHERE t.NODE_TYPE_NEW = '选择'
order by t.node_id
```
