### 调试
#### 抛错
```
schema.包名.函数名			--调用包内对象格式
RAISE EXCEPTION '错误信息'; 	---抛出异常	
RAISE EXCEPTION '错误信息' USING ERRCODE = 'P0001'; 	--抛出异常 (带错误码)	
EXCEPTION WHEN SQLSTATE 'P0001' THEN ...  --捕获特定异常，其中SQL错误为SQLERRM
```

### 对比Oracle
功能对比				Oracle 语法 (不兼容)									PostgreSQL 语法 (你应该用的)	
抛出异常				raise_application_error(-20001, '错误信息'); 			RAISE EXCEPTION '错误信息'; 	
抛出异常 (带错误码)		raise_application_error(-20001, '错误信息'); 			RAISE EXCEPTION '错误信息' USING ERRCODE = 'P0001'; 	
捕获特定异常			EXCEPTION WHEN -20001 THEN ... 							EXCEPTION WHEN SQLSTATE 'P0001' THEN ... 	
输出调试信息			DBMS_OUTPUT.PUT_LINE('消息'); 							RAISE NOTICE '消息';
