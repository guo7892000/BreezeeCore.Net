### 返回SYS_REFCURSOR游标变量
在Oracle数据库中，SYS_REFCURSOR是一种特殊的引用游标，它允许存储过程和函数返回多个行和列的结果集。这对于编写灵活的SQL代码非常有用，
特别是在需要从多个表中选择数据或将复杂的查询结果集返回给调用者时。使用SYS_REFCURSOR时，记得在不再需要时关闭游标，
以释放资源。这可以通过在PL/SQL块中使用CLOSE语句来完成。
```
/*创建存储过程*/
CREATE OR REPLACE PROCEDURE get_employee_details(
    p_dept_id IN NUMBER,
    p_emp_cursor OUT SYS_REFCURSOR
) AS
BEGIN
    OPEN p_emp_cursor FOR
        SELECT employee_id, name, salary
        FROM employees
        WHERE department_id = p_dept_id;
END;
/

/*调用存储过程*/
DECLARE
    v_emp_cursor SYS_REFCURSOR;
    v_emp_id employees.employee_id%TYPE;
    v_name employees.name%TYPE;
    v_salary employees.salary%TYPE;
BEGIN
    -- 调用存储过程
    get_employee_details(10, v_emp_cursor);
    
    -- 循环读取游标中的数据
    LOOP
        FETCH v_emp_cursor INTO v_emp_id, v_name, v_salary;
        EXIT WHEN v_emp_cursor%NOTFOUND;
        
        -- 处理数据，例如打印输出
        DBMS_OUTPUT.PUT_LINE('Employee ID: ' || v_emp_id || ', Name: ' || v_name || ', Salary: ' || v_salary);
    END LOOP;
    
    -- 关闭游标
    CLOSE v_emp_cursor;
END;
/
```
