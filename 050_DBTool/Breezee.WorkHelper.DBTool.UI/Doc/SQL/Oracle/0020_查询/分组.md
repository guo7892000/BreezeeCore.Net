### 分组
#### 筛选重复行中数量小的记录
```
select *
 from (SELECT T.*,
              row_number() over (PARTITION BY T.MFG_CODE, T.Date_Str order by CNT desc) as RNUM
         FROM (select Y.MFG_CODE,
                      Y.Date_Str,
                      t.batch_id,
                      count(1) as CNT
                 from T_BATCH t
                 join T_PRODUCT_QTY Y
                   on t.batch_id = Y.taskid
                 join T_PRODUCT_DATE D
                   on Y.Date_Str = D.Date_Str
                  and Y.MFG_CODE = D.MFG_CODE
                  and D.DEAL_FLAG = '0'
                where t.if_code = 'YCERP-JFBOM-001'
                  and Y.Create_Time < sysdate - 5 / 24
                group by Y.MFG_CODE, Y.Date_Str, t.batch_id) T) TT
where TT.RNUM > 1
```

### 分组后排序在外层再获取第一条：不要在分组时取第1条记录，那样不会达到预期效果。
```
Oracle包中执行以下SQL，会从查询结果：LFNA4LKA、LFNA9LKA。如果把把注释掉的and rownum = 1重新启用，为什么有时返回LFNA9LKA？
错误SQL：
select VN.VIN, /*VIN前八位*/
    max(NT.ZZL) ZZL, /*总质量*/
    max(NT.ZBZL) AS ZBZL, /*整备质量*/
    max(NT.ZZL2) as ZZL2 /*载质量*/
FROM EBOM_T_S3DB_NOTICE NT /*公告*/
join MBOM_T_QDPUBFILEVIN VN /*青汽公告VIN列表*/
    on VN.PUBLISH_PRD_NO = NT.CLXH
    and VN.VIN7_CODE = 'K'
    and VN.VIN8_CODE = 'A'
    and VN.VIN6_CODE IN ('L', 'W')
where NT.CLXH = 'CA5091CCYP40K42L2E6A84'
 and rownum = 1
group by VN.VIN
order by VN.VIN

正确的SQL：
SELECT * FROM (
    SELECT VN.VIN,
           MAX(NT.ZZL) ZZL,
           MAX(NT.ZBZL) AS ZBZL,
           MAX(NT.ZZL2) AS ZZL2
      FROM EBOM_T_S3DB_NOTICE NT
      JOIN MBOM_T_QDPUBFILEVIN VN
        ON VN.PUBLISH_PRD_NO = NT.CLXH
       AND VN.VIN7_CODE = 'K'
       AND VN.VIN8_CODE = 'A'
       AND VN.VIN6_CODE IN ('L', 'W')
     WHERE NT.CLXH = 'CA5091CCYP40K42L2E6A84'
     GROUP BY VN.VIN
     ORDER BY VN.VIN
) WHERE ROWNUM = 1;
```
