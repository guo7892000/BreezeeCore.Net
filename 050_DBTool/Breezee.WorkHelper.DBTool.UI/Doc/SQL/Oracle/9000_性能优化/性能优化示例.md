## 性能优化示例
### 真实案例：针对父子零件路线不一致的包中存储过程的调优
【规则简述】：  
1、基础规则：子件的装配路线和父件的制造路线比较。每个零件，只查到第一个不符合的件即可。
2、子件只有制造路线没有装配路线时，不提醒。  
3、子件、当前件、父件如果是实体件但没有路线，不做提醒。  
4、总、总(装)、总(分)、总(发)默认都是一样的，不需要提醒。比如子件路线是协=总，父件路线是总(分)=总(装)。不需要提醒。  
5、针对当前件为协=协、协=协(委)、协(委)=协、协(委)=协(委)：如1级至多4级的所有父件都为虚拟件时，要提醒。  
6、向下最多查找2层子件：如子件为虚拟件，还得向下查找；如子件为实体件，符合则跳过，不符合则提醒。  
7、向上最多找4层父件：如父件为虚拟件，还得向上查找；如父件为实体件，符合则跳过，不符合则提醒。  
    展开所有1级父件，但只针对1级父件为虚拟件展开2级父件，3、4级父件同理。  
8、父子在MBOM表中存在才判断。  
9、展开的结构SQL临时表中，父子件一样的，只会有一条记录！  
10、针对PDM单和PCO的，取的路线都要用最新的。   
11、当前件为无须路线时，要拿其子件和父件进行比较（注：不符合结果中，当前件依然是该无须路线件）。  
【要求】：得到结果得在1分钟左右，多了界面会超时，导致显示失败！！   
【实现过程探索】：  
【方案1】：使用物理临时表  
1、先根据会话ID删除计算范围件，再将本次待计算零件写入待计算临时表。  
2、针对计算范围件的共2级子件，先根据会话ID删除向下展开临时表：  
  2.1 先根据计算范围件，计算其1级子件，写入向下展开临时表。  
  2.2 再根据其1级子件，计算其2级子件，并写入向下展开临时表。  
3、针对计算范围件的共4级父件，先根据会话ID删除向上展开临时表：  
  3.1 先根据计算范围件，计算其1级父件，写入向上展开临时表。  
  3.2 针对1级父件，查找其2级父件，写入向上展开临时表。   
  3.3 同理，实现3、4级父件的计算，并写入向上展开临时表。  
4、利用向下和同上的结果及当前件的路线、跟父子件进行比较，得到不符合项。  
问题：因为向上计算父件的零件非常多，如有几十万数据，如果不使用并发写入，那么写1级父件就花了2分多钟。重复计算时，删除之前计算好的向上临时表也花了12秒。  
如采用并发写入，写入速度快了，但出现并发锁表机率也大大增加。因为该计算是很频繁的。所以方案1最终被抛弃了。  

【方案2】：使用WITH语法的SQL临时表（无任何物理临时表）    
使用用WITH语法，从输入参数，计算范围零件，向下展开2层，向上展开4层，计算不符合项，最终结果，用一个渐近式的SQL实现（后一个SQL使用前面的临时表）。  
最终得到结果在1分钟以内，完美解决。但这种方式也有点小问题：因为SQL太长，用PLSQL DEVELOPER在测试环境编译，有时会失败，要多试几次，并且比较耗时（跟数据库配置有关，测试库很慢，但生产环境几秒就好了），需要耐心等待编译成功！！  
另外，在SQL中调用函数实现某列值的转换时，请不要使用SQL方式，那样会比较耗时，最好是使用循环、字符处理那样的操作，那样效率最高！！  
另外，为了方便复制SQL调试，调用包内的方法也增加了包名前缀。

CREATE OR REPLACE Package Body PKG_JF_QD_PARENT_CHILD_COMP Is
  /*
  功能模块：【获取路线】
  功能描述：获取制造路线或装配路线，用于父子路线不一致、柳柳分析
  重点描述：无
  业务规则：
    1、针对-取第一位，针对/取全部。
    2、本算法针对制造路线或装配路线。
  修订历史：
      20260312  新增，针对-取第一位，针对/取第一位。 huangguohui
      20260314  针对/取全部。 huangguohui
  */
  Function F_GET_ROUTEMFG_STR(ac_str In Varchar2 --字符串
                              ) Return Varchar2 DETERMINISTIC
    PARALLEL_ENABLE Is
    PRAGMA UDF;
    lc_result Varchar2(4000);
  Begin
    -- 1.处理 '-'
    If INSTR(ac_str, '-') > 0 Then
      lc_result := SUBSTR(ac_str, 1, INSTR(ac_str, '-') - 1);
    Else
      lc_result := ac_str;
    End If;
    -- 2.相同类型的转换：Q02, Q03, Q04, Q05 -> C07
    If lc_result In ('Q02', 'Q03', 'Q04', 'Q05') Then
      lc_result := 'C07';
    else
      --总(装)-Q02、总(发)-Q03、总(分)-Q04、总(厢)-Q05，统一替换为总
      lc_result := Replace(lc_result, 'Q02', 'C07');
      lc_result := Replace(lc_result, 'Q03', 'C07');
      lc_result := Replace(lc_result, 'Q04', 'C07');
      lc_result := Replace(lc_result, 'Q05', 'C07');
    End If;

    Return(lc_result);
  End F_GET_ROUTEMFG_STR;

  /*
  功能模块：【比较路线】
  功能描述：比较路线是否一致
  重点描述：无
  业务规则：1、只要子件的装配路线与父件的制造路线有交集，则返回1，否则返回0。
  修订历史：
      20260314  新增，只要子件的装配路线与父件的制造路线有交集，则返回1，否则返回0。 huangguohui
      20260318  性能优化，改用文本分隔后存入MAP，再通过MAP是否存在来判断返回。 huangguohui
  */
  Function F_COMP_ROUTEMFG(pr_mfg_str  In Varchar2, --父件的制造路线
                           ch_assm_str In Varchar2 --子件的装配路线
                           ) Return Varchar2 DETERMINISTIC
    PARALLEL_ENABLE Is
    PRAGMA UDF;
    lc_result Varchar2(10) := '0';

    -- 定义关联数组类型用于存储元素及其计数
    TYPE t_count_map IS TABLE OF PLS_INTEGER INDEX BY VARCHAR2(4000);

    l_map1 t_count_map;
    l_map2 t_count_map;

    l_token VARCHAR2(4000);
    l_pos   PLS_INTEGER;
    l_start PLS_INTEGER;
    l_len   PLS_INTEGER;

    l_key VARCHAR2(4000);
  Begin

    --快速失败：如果两个字符串完全相同（包括顺序），直接返回1
    IF pr_mfg_str = ch_assm_str THEN
      RETURN '1';
    END IF;

    -- 如果其中一个为空，另一个不为空，则返回0
    IF (pr_mfg_str IS NULL AND ch_assm_str IS NOT NULL) OR
       (pr_mfg_str IS NOT NULL AND ch_assm_str IS NULL) THEN
      RETURN '0';
    END IF;
    --两个同时为空，返回0
    IF pr_mfg_str IS NULL AND ch_assm_str IS NULL THEN
      RETURN '0';
    END IF;

    -- 辅助过程：解析字符串并填充计数Map（计数器不作为判断项）
    -- 为了性能，我们将解析逻辑内联或使用本地逻辑，这里为了代码清晰写在一个块里
    -- 解析 pr_mfg_str
    l_start := 1;
    l_len   := LENGTH(pr_mfg_str);

    WHILE l_start <= l_len LOOP
      l_pos := INSTR(pr_mfg_str, '/', l_start);
      IF l_pos = 0 THEN
        l_token := SUBSTR(pr_mfg_str, l_start);
        l_start := l_len + 1; -- 结束循环
      ELSE
        l_token := SUBSTR(pr_mfg_str, l_start, l_pos - l_start);
        l_start := l_pos + 1;
      END IF;

      -- 计入 Map1
      IF l_map1.EXISTS(l_token) THEN
        l_map1(l_token) := l_map1(l_token) + 1;
      ELSE
        l_map1(l_token) := 1;
      END IF;
    END LOOP;

    -- 解析ch_assm_str
    l_start := 1;
    l_len   := LENGTH(ch_assm_str);

    WHILE l_start <= l_len LOOP
      l_pos := INSTR(ch_assm_str, '/', l_start);
      IF l_pos = 0 THEN
        l_token := SUBSTR(ch_assm_str, l_start);
        l_start := l_len + 1;
      ELSE
        l_token := SUBSTR(ch_assm_str, l_start, l_pos - l_start);
        l_start := l_pos + 1;
      END IF;

      -- 计入 Map2
      IF l_map2.EXISTS(l_token) THEN
        l_map2(l_token) := l_map2(l_token) + 1;
      ELSE
        l_map2(l_token) := 1;
      END IF;
    END LOOP;

    -- 遍历其中一个Map，检查另一个Map中是否存对应KEY
    l_key := l_map1.FIRST;
    WHILE l_key IS NOT NULL LOOP
      IF l_map2.EXISTS(l_key) THEN
        RETURN '1'; --包含相同键，返回1
      END IF;
      --下一个记录
      l_key := l_map1.NEXT(l_key);
    END LOOP;

    --返回结果
    Return(lc_result);
  End F_COMP_ROUTEMFG;

  /*
  功能模块：【计算零件所有父子件的符合类型】
  功能描述：计算所有父子件的符合类型：
    返回【K-A-xxxx】：表示所有符合，其中【A】表示首个比较层级，如ME、C1、C2、P1、P2、P3、P4，【xxx】用于进一步说明符合的场景。
    返回【x,y】：表示返回层次范围，其中x、y的范围是(-2、-1、0、1、2、3、4)，且【y】必须大于【x】。
  重点描述：无
  业务规则：
    1、柳柳不提醒。
    2、协协提醒。
    3、含销整车不提醒。
    4、未维护路线时不提醒。
    5、当前件有路线时，先比较子件有没符合，如有不符合，直接返回；如符合，则还要跟父件比较是否符合。
    6、针对当前件为虚拟件时，会使用C1件比较，比较逻辑同上。如当前件、C1都是虚拟件，那么会使用C2来比较；
      如C2件也为虚拟件，那就直接返回正常。
  修订历史：
      20260314 新增，只要子件的装配路线与父件的制造路线有交集，则返回1，否则返回0。 huangguohui
      20260319 业务提出新增规则：不管制造路线，只要装配路线包含销，并且这个件挂在整车下，就不需要提醒 huangguohui
      20260320 针对存在于无路线表的零件，即使路线变更表有数据，也要将制造路线和装配路线取成空值。huangguohui
      20260322 将原来2级子件、4级父件各自判断，合并为所有父子件一起判断，即当前件路线为空时，需要取子件路线跟父件比较。huangguohui
      20260408 2级参数放最前面；另外为方便找问题，将正常数据返回值修改为：K-，后面加上符合的场景说明 huangguohui
      20260410 原来的逻辑不够清晰，重构整个逻辑：确定计算3个比较节点（当前件、子件、父件）。 huangguohui
  */
  FUNCTION F_CALC_FITFLAG(I_C2_ROUTE_MFG_STR   VARCHAR2, --2级子件制造路线
                          I_C2_ROUTE_ASSEM_STR VARCHAR2, --2级子件装配路线
                          I_C2_NOROUT          NUMBER, --2级子件无须路线标识
                          I_C1_ROUTE_MFG_STR   VARCHAR2, --1级子件制造路线
                          I_C1_ROUTE_ASSEM_STR VARCHAR2, --1级子件装配路线
                          I_C1_NOROUT          NUMBER, --1级子件无须路线标识
                          I_ROUTE_MFGSTR       VARCHAR2, --当前件制造路线
                          I_ROUTE_ASSEMSTR     VARCHAR2, --当前件装配路线
                          I_NOROUT             VARCHAR2, --当前件无须路线标识
                          I_CAR_FLAG           VARCHAR2, --当前件整车标志
                          I_P1_ROUTE_MFG_STR   VARCHAR2, --1级父件制造路线
                          I_P1_ROUTE_ASSEM_STR VARCHAR2, --1级父件装配路线
                          I_P1_NOROUT          VARCHAR2, --1级父件无路线标识
                          I_P1_CAR_FLAG        VARCHAR2, --1级父件整车标志
                          I_P2_ROUTE_MFG_STR   VARCHAR2, --2级父件制造路线
                          I_P2_ROUTE_ASSEM_STR VARCHAR2, --2级父件装配路线
                          I_P2_NOROUT          VARCHAR2, --2级父件无路线标识
                          I_P2_CAR_FLAG        VARCHAR2, --2级父件整车标志
                          I_P3_ROUTE_MFG_STR   VARCHAR2, --3级父件制造路线
                          I_P3_ROUTE_ASSEM_STR VARCHAR2, --3级父件装配路线
                          I_P3_NOROUT          VARCHAR2, --3级父件无路线标识
                          I_P3_CAR_FLAG        VARCHAR2, --3级父件整车标志
                          I_P4_ROUTE_MFG_STR   VARCHAR2, --4级父件制造路线

                          I_P4_CAR_FLAG        VARCHAR2 --4级父件整车标志
                          ) RETURN VARCHAR2 DETERMINISTIC
    PARALLEL_ENABLE IS

    v_result    VARCHAR2(500);
    me_null     boolean; --当前件制造路线空标识

    c1_assm_c43 varchar2(10); --1级子件的装配路线包含销标志：0-不包含，1-包含

  BEGIN

        v_cp_3_asm := I_P3_ROUTE_ASSEM_STR;
        v_cp_3_pos := 'P3';
      elsif I_P4_NOROUT = 0 then
        --3.4 P4件非无须路线
        v_cp_3_mfg := I_P4_ROUTE_MFG_STR;
        v_cp_3_asm := I_P4_ROUTE_ASSEM_STR;
        v_cp_3_pos := 'P4';
      end if;
      --比较
      if v_cp_3_mfg = 'Q31' And v_cp_3_asm = 'Q31' Then
        null; --【柳柳】不需要比较
      elsif v_cp_3_mfg is not null and v_cp_1_asm is not null then
        if PKG_JF_QD_PARENT_CHILD_COMP.F_COMP_ROUTEMFG(v_cp_3_mfg,
                                                        v_cp_1_asm) = '0' then
          return '-2,' || replace(v_cp_3_pos, 'P', ''); --父件与当前件不符合，给出提醒
        end if;
      end if;
      return 'K-C2-没有不符合项';
      --【C2实件】结束

    elsif I_P1_NOROUT = 0 then
      --2.4 【P1实件】开始
      --协协：提醒，这里不足4层，所以注释掉
      /*if I_P1_ROUTE_MFG_STR In ('C10', 'Q19') And
         I_P1_ROUTE_ASSEM_STR In ('C10', 'Q19') And
         p2_null And p3_null And p4_null Then
        return '1,4'; --C2件路线：协=协或协(委)=协(委)；往上找4层的过程中父件都是虚拟件，给出提醒
      end if;*/
      --2.4.2 得到【比较节点1】
      v_cp_1_mfg := I_P1_ROUTE_MFG_STR;
      v_cp_1_asm := I_P1_ROUTE_ASSEM_STR;
      v_cp_1_pos := 'P1';
      --柳柳：不提醒
      if v_cp_1_mfg = 'Q31' And v_cp_1_asm = 'Q31' Then
        return 'K-P1-P1-LL'; --【Px柳柳】不提醒:OK
      end if;
      --子件装配路线为空：不提醒
      if v_cp_1_asm is null Then
        return 'K-P1-P1-装配路线为空'; --【子件装配路线为空】不提醒:OK
      end if;

      --2.4.3 计算得到【比较节点2】：从P1开始
      if I_P2_NOROUT = 0 then
        --2.4.3.3 P2件非无须路线
        v_cp_2_mfg := I_P2_ROUTE_MFG_STR;
        v_cp_2_asm := I_P2_ROUTE_ASSEM_STR;
        v_cp_2_pos := 'P2';
      elsif I_P3_NOROUT = 0 then
        --2.4.3.4 P3件非无须路线
        v_cp_2_mfg := I_P3_ROUTE_MFG_STR;
        v_cp_2_asm := I_P3_ROUTE_ASSEM_STR;
        v_cp_2_pos := 'P3';
      elsif I_P4_NOROUT = 0 then
        --2.4.3.5 P4件非无须路线
        v_cp_2_mfg := I_P4_ROUTE_MFG_STR;
        v_cp_2_asm := I_P4_ROUTE_ASSEM_STR;
        v_cp_2_pos := 'P4';
      else
        return 'K-P1-C2至P4都是虚拟件';
      end if;
      --比较
      if v_cp_2_mfg = 'Q31' And v_cp_2_asm = 'Q31' Then
        null; --【柳柳】不需要比较
      elsif v_cp_2_mfg is not null and v_cp_1_asm is not null then
        if PKG_JF_QD_PARENT_CHILD_COMP.F_COMP_ROUTEMFG(v_cp_2_mfg,
                                                        v_cp_1_asm) = '0' then
          return '1,' || replace(v_cp_2_pos, 'P', ''); --父件与当前件不符合，给出提醒
        end if;
      end if;
      return 'K-P1-没有不符合项';
      --【P1实件】结束

    elsif I_P2_NOROUT = 0 then
      --2.5 【P2实件】开始
      --2.5.2 得到【比较节点1】
      v_cp_1_mfg := I_P2_ROUTE_MFG_STR;
      v_cp_1_asm := I_P2_ROUTE_ASSEM_STR;
      v_cp_1_pos := 'P2';
      --柳柳：不提醒
      if v_cp_1_mfg = 'Q31' And v_cp_1_asm = 'Q31' Then
        return 'K-P2-P1-LL'; --【Px柳柳】不提醒:OK
      end if;
      --子件装配路线为空：不提醒
      if v_cp_1_asm is null Then
        return 'K-P2-P2-装配路线为空'; --【子件装配路线为空】不提醒:OK
      end if;

      --2.5.3 计算得到【比较节点2】：从P1开始
      if I_P3_NOROUT = 0 then
        --2.5.3.4 P3件非无须路线
        v_cp_2_mfg := I_P3_ROUTE_MFG_STR;
        v_cp_2_asm := I_P3_ROUTE_ASSEM_STR;
        v_cp_2_pos := 'P3';
      elsif I_P4_NOROUT = 0 then
        --2.5.3.5 P4件非无须路线
        v_cp_2_mfg := I_P4_ROUTE_MFG_STR;
        v_cp_2_asm := I_P4_ROUTE_ASSEM_STR;
        v_cp_2_pos := 'P4';
      else
        return 'K-P1实件但C2至P4都是虚拟件';
      end if;
      --比较
      if v_cp_2_mfg = 'Q31' And v_cp_2_asm = 'Q31' Then
        null; --【柳柳】不需要比较
      elsif v_cp_2_mfg is not null and v_cp_1_asm is not null then
        if PKG_JF_QD_PARENT_CHILD_COMP.F_COMP_ROUTEMFG(v_cp_2_mfg,
                                                        v_cp_1_asm) = '0' then
          return '2,' || replace(v_cp_2_pos, 'P', ''); --父件与当前件不符合，给出提醒
        end if;
      end if;
      return 'K-P2-没有不符合项';
      --【P2实件】结束

    elsif I_P3_NOROUT = 0 then
      --2.6 【P3实件】开始
      v_cp_1_mfg := I_P3_ROUTE_MFG_STR;
      v_cp_1_asm := I_P3_ROUTE_ASSEM_STR;
      v_cp_1_pos := 'P3';
      --柳柳：不提醒
      if v_cp_1_mfg = 'Q31' And v_cp_1_asm = 'Q31' Then
        return 'K-P3-P3-LL'; --【Px柳柳】不提醒:OK
      end if;
      --子件装配路线为空：不提醒
      if v_cp_1_asm is null Then
        return 'K-P3-P3-装配路线为空'; --【子件装配路线为空】不提醒:OK
      end if;

      --2.5.3 计算得到【比较节点2】：从P1开始
      if I_P4_NOROUT = 0 then
        --2.5.3.5 P4件非无须路线
        v_cp_2_mfg := I_P4_ROUTE_MFG_STR;
        v_cp_2_asm := I_P4_ROUTE_ASSEM_STR;
        v_cp_2_pos := 'P4';
      else
        return 'K-P3-C2至P4是虚拟件';
      end if;
      --比较
      if v_cp_2_mfg = 'Q31' And v_cp_2_asm = 'Q31' Then
        null; --【柳柳】不需要比较
      elsif v_cp_2_mfg is not null and v_cp_1_asm is not null then
        --父件维护了路线
        if PKG_JF_QD_PARENT_CHILD_COMP.F_COMP_ROUTEMFG(v_cp_2_mfg,
                                                        v_cp_1_asm) = '0' then
          return '3,' || replace(v_cp_2_pos, 'P', ''); --父件与当前件不符合，给出提醒
        end if;
      end if;
      return 'K-P3-没有不符合项';
      --【P3实件】结束

    else
      --2.7 只有P4节点，无从比较，直接返回真
      return 'K-P4-C2至P3都是虚拟件';
    end if;
    --返回结果
    RETURN v_result;
  END;

  /*
  功能模块：【青岛父子路线不一致分析、柳柳分析】
  功能描述：获取一位制造路线或装配路线，用于父子、柳柳分析。
    包括3种场景（下述范围零件都是当前件）：
      1、PCO：只支持i_cncid传入一个PCO流水号，计算其下所有件的不一致分析。
      2、PDM：只支持i_cncid传入一个PDM单号，计算其下所有件的不一致分析。
      3、零件版本：支持逗号分隔多个零件（每个零件再以分号分隔零件号与版本），计算它们的不一致分析。
  重点描述：这里不使用中间表和结果表，直接通过SQL临时表（WITH AS）实现最终结果查询。
     本存储过程在测试环境编译会很慢（10分钟左右，但生产环境很快），因为使用太多WITH临时表，记得多试几次！！
     当认为有数据应该提醒，但没查到记录时，可以查询分析后的结果表（T_ALL）来分析（主要是NOT_FIT等字段信息）。
  业务规则：
    一、父子路线不一致分析
      1、基础规则：子件的装配路线和父件的制造路线比较。每个零件，只查到第一个不符合的件即可。
      2、子件只有制造路线没有装配路线时，不提醒。
      3、子件、当前件、父件如果是实体件但没有路线，不做提醒。
      4、总、总(装)、总(分)、总(发)默认都是一样的，不需要提醒。比如子件路线是协=总，父件路线是总(分)=总(装)。不需要提醒。
      5、针对当前件为协=协、协=协(委)、协(委)=协、协(委)=协(委)：如1级至多4级的所有父件都为虚拟件时，要提醒。
      6、向下最多查找2层子件：如子件为虚拟件，还得向下查找；如子件为实体件，符合则跳过，不符合则提醒。
      7、向上最多找4层父件：如父件为虚拟件，还得向上查找；如父件为实体件，符合则跳过，不符合则提醒。
         展开所有1级父件，但只针对1级父件为虚拟件展开2级父件，3、4级父件同理。
      8、父子在MBOM表中存在才判断。
      9、展开的结构SQL临时表中，父子件一样的，只会有一条记录！
      10、针对PDM单和PCO的，取的路线都要用最新的
      11、当前件为无须路线时，要拿其子件和父件进行比较（注：不符合结果中，当前件依然是该无须路线件）。
      12、整车件会作为总-总，那么其无须路线标识也会当作否（即0）来比较。
    二、柳柳分析：【柳柳分析起点】
      1、最近一次工厂标识的变更：由【柳】或空，修改为：【青】或【青柳】。
      2、当前零件的制造路线为【柳】，即Q31
      3、查找范围内的零件及其下所有子件。
      4、按照规则不需要编制路线的件不需要提醒。
      5、PDM采用、变更通知书中“新建零件”不需要提醒。
  修改历史：
      20260205 新增，按新逻辑处理，父件的记录中存父件的基础信息（之前是子件），并增加显示零件及版本字段用于前端展示 huangguohui
      20260212 子件、当前件、父件如果是实体件但没有路线，不做提醒 huangguohui
      20260312 直接使用SQL查询结果（WITH方式的SQL临时表），不再使用物理中间表和结果表，速度大大提升！！ huangguohui
      20260314 针对PDM单和PCO的，取的路线都要用最新的；按新逻辑修正柳柳判断 huangguohui
      20260321 修正路线取最新的逻辑：路线变更表按零件版本分组，按创建时间倒序取第一个 huangguohui
      20260322 所有计算的零件范围都是单据下所有件（含无须路线件）作为当前件，然后比较时如当前件是无须路线件，
               那么会取其子件来跟父件比较，这个是一个相对改动比较大的逻辑！ huangguohui
      20260408 由于F_CALC_FITFLAG返回值内容变化，而相应修改；并且针对整车件，其无须路线标识取0来做比较。  huangguohui
  */
  Procedure P_ALL_COMP(i_ConversationId In Varchar2, --业务会话（可选）
                       i_mfgcentercode  In Varchar2, --生产中心（必填）
                       i_cncid          In Varchar2, --PDM变更单号或PCO单流水号
                       i_ItemIDVer      In Varchar2, --展开项目ID及版本（支持逗号分隔多个，每个零件以分号分隔零件号与版本）
                       i_QueryDate      In Varchar2, --查询日期（可选）
                       i_OperatorId     In Varchar2, --当前用户（可选）
                       o_ResData_pc_cur Out Sys_Refcursor, --返回父子不一致结果集
                       o_ResData_ll_cur Out Sys_Refcursor, --返回柳柳结果集
                       o_Return_Code    Out Varchar2, --返回代码
                       o_Error_Message  Out Varchar2, --返回业务错误信息
                       o_Sqlerrm        Out Varchar2 --返回存储过程异常
                       ) Is
    v_ConversationId Varchar2(200); --会话ID，如不传入，则生成一个新的GUID
    v_QueryDate      Varchar2(12); --查询日期，如不传入，则取当天
    v_OperatorId     Varchar2(100); --操作人，如不传入，则取admin
  Begin
    o_Return_Code   := pkg_com_define.const_error;
    o_Error_message := pkg_com_define.const_error_message;
    --非必要参数的初始化
    v_ConversationId := nvl(i_ConversationId, sys_guid()); --默认新的GUID
    v_QueryDate      := nvl(i_QueryDate, to_char(sysdate, 'yyyyMMdd')); --默认当天
    v_OperatorId     := nvl(i_OperatorId, 'admin'); --默认admin
    --入参判断
    if i_mfgcentercode is null then
      o_Error_message := '入参生产中心不能为空！';
      return;
    end if;
    if i_cncid is null and i_ItemIDVer is null then
      o_Error_message := '入参【通知书号】、【零件;版本】至少一项不能为空！';
      return;
    end if;

    --1、查询父子路线不一致分析结果
    Open o_ResData_pc_cur FOR
      WITH T_IN_PARA AS /*【输入参数】原始*/
       (SELECT i_cncid as CNCID, /*PDM变更单号：i_cncid*/
               i_mfgcentercode AS MFG_CODE, /*工厂ID：i_mfgcentercode*/
               i_ItemIDVer as ITEM_ID_VER, /*展开项目ID：i_ItemIDVer，（支持逗号分隔多个，每个零件以分号分隔）*/
               v_ConversationId AS CONVERSATIONID, /*会话ID*/
               v_QueryDate AS QRY_DATE, /*查询日期*/
               v_OperatorId as OPERATOR_ID, /*操作人*/
               '99999999' AS MAX_DATE_END
          FROM DUAL),
      T_PARAM AS /*【输入参数】增加计算类型*/
       (select A.*,
               CASE
                 WHEN A.ITEM_ID_VER IS NOT NULL THEN
                  '3'
                 WHEN A.CNCID LIKE 'PCO%' THEN
                  '1'
                 ELSE
                  '2'
               END CAL_TYPE /*计算类型：1-PCO，2-PDM，3-按零件计算*/
          from T_IN_PARA A),
      T_ITM_LI_IN AS /*【零件版本】入参*/
       (Select substr(column_value, 0, instr(column_value, ';') - 1) as ITEM_ID,
               substr(column_value, instr(column_value, ';') + 1) AS VER_NUM
          From Table(pkg_com_util.F_GetStrConvertCol((select ITEM_ID_VER
                                                       from T_IN_PARA),
                                                     ','))),
      T_ROUTE AS /*【零件路线表】传入工厂的零件版本只取最新那一条记录*/
       (select AA.*
          FROM (SELECT T.MFG_CENTER_CODE,
                       T.ITEM_ID,
                       T.VER_NUM,
                       T.CNC_EDIT,
                       CASE
                         WHEN W.ITEM_ID IS NULL THEN
                          T.ROUTE_MFGSTR
                         ELSE
                          NULL
                       END AS ROUTE_MFGSTR, /*制造路线：无路线表存在时取空，用于后面的判断*/
                       CASE
                         WHEN W.ITEM_ID IS NULL THEN
                          T.ROUTE_ASSEMSTR
                         ELSE
                          NULL
                       END AS ROUTE_ASSEMSTR, /*装配路线：无路线表存在时取空，用于后面的判断*/
                       CASE
                         WHEN W.ITEM_ID IS NULL THEN
                          0
                         ELSE
                          1
                       END AS NOROUT_T, /*无路线标识：0-否，1-是*/
                       ROW_NUMBER() over (PARTITION BY T.ITEM_ID, T.VER_NUM order by T.CREATE_TIME desc) as RNUM /*按零件号和版本分组，按创建时间倒序排列取第一个*/
                  FROM MBOM_T_QDITMROUTE_HIS T /*路线变更表*/
                  JOIN T_PARAM P /*参数*/
                    ON T.MFG_CENTER_CODE = P.MFG_CODE
                  left join MBOM_T_QDROUTMFGITM W /*无路线表*/
                    on W.MFG_CENTER_CODE = T.MFG_CENTER_CODE
                   And W.ITEM_ID = T.ITEM_ID
                   And W.VER_NUM = T.VER_NUM) AA
         where AA.RNUM = 1),
      T_ITM_LI AS /*【零件版本】计算清单：注要包括无须配置路线表的*/
       (Select A.ITEM_ID, --零件号
               A.VER_NUM --版本
          From T_ITM_LI_IN A
          JOIN T_PARAM P
            on P.CAL_TYPE = '3'
         where exists (select 1 --存在于MBOM表的
                  from MBOM_T_MFGITM M
                 where M.MFG_CENTER_CODE = P.MFG_CODE
                   AND M.ITEM_ID = A.ITEM_ID
                   AND M.VER_NUM = A.VER_NUM)),
      T_PCO_LI as /*【PCO】零件列表：跳过无制造路线的，注要包括无须配置路线表的*/
       (Select h.ITEM_ID, --零件号
               h.VER_NUM --版本
          From mbom_t_qditmroute_his h /*路线变更表：这里还是使用最原始的路线变更表*/
          join T_PARAM P
            on P.CAL_TYPE = '1'
           and H.MFG_CENTER_CODE = P.MFG_CODE
          Join ebom_t_itmengc t
            On h.item_id = t.item_id
           And h.ver_num = t.ver_num
         Where h.cnc_edit = P.CNCID
           And h.ROUTE_MFGSTR Is Not Null),
      T_PDM_LI As /*【PDM】零件列表：注要包括无须配置路线表的*/
       (Select A.ITEM_ID, --零件号
               N.VER_NUM, --版本
               P.MFG_CODE,
               P.QRY_DATE
          From EBOM_T_CNCQ_ITEM A
          Join EBOM_T_ITMENGC N
            On A.ITEM_ID = N.ITEM_ID
           And A.VER_NUM_ORIG = N.VER_NUM_ORIG
          JOIN T_PARAM P
            on P.CAL_TYPE = '2'
         Where A.CNC_ID = P.CNCID
           and exists (select 1 --存在于MBOM表的
                  from MBOM_T_MFGITM M
                 where M.MFG_CENTER_CODE = P.MFG_CODE
                   and M.ITEM_ID = A.ITEM_ID
                   AND M.VER_NUM = N.VER_NUM)),
      T_FN_LI as /*【最终的零件列表】*/
       (Select A.ITEM_ID, A.VER_NUM
          From T_PDM_LI A
        union all
        Select A.ITEM_ID, A.VER_NUM
          From T_PCO_LI A
        union all
        Select A.ITEM_ID, A.VER_NUM
          From T_ITM_LI A),
      T_ITEMS AS /*【计算的零件范围】都是有制造路线的。路线取最新的*/
       (SELECT sys_guid() as ITEM_TEMP_ID,
               A.ITEM_ID,
               A.VER_NUM,
               R1.NOROUT_T, --无须路线标志
               PKG_JF_QD_PARENT_CHILD_COMP.F_GET_ROUTEMFG_STR(R1.route_mfgstr) as ROUTE_MFGSTR,
               PKG_JF_QD_PARENT_CHILD_COMP.F_GET_ROUTEMFG_STR(R1.Route_Assemstr) as ROUTE_ASSEMSTR,
               R1.route_mfgstr as ROUTE_MFGSTR_S, /*原制造路线编码*/
               R1.Route_Assemstr as ROUTE_ASSEMSTR_S /*原装配路线编码*/
          FROM T_FN_LI A
          JOIN T_PARAM P
            ON 1 = 1
          LEFT JOIN T_ROUTE R1 /*路线变更临时表*/
            ON R1.MFG_CENTER_CODE = P.MFG_CODE
           AND R1.ITEM_ID = A.ITEM_ID
           AND R1.VER_NUM = A.VER_NUM),
      T_LIST AS /*【最终计算的零件范围】:排除柳柳件*/
       (select A.*,
               case
                 when A.ROUTE_MFGSTR is null and
                      (A.ITEM_ID like 'GPCA%' or A.ITEM_ID like 'GPLT%') THEN
                  '1'
                 else
                  '0'
               end AS CAR_FLAG /*整车标志：0-否，1-是*/
          FROM T_ITEMS A
         where not exists (select 1
                  FROM T_ITEMS H
                 where H.ROUTE_MFGSTR = 'Q31'
                   and H.ROUTE_ASSEMSTR = 'Q31'
                   and A.ITEM_TEMP_ID = H.ITEM_TEMP_ID)),
      T_DOWN_1 as /*【1级子件】*/
       (SELECT T.ROWID AS RID,
               T.ITEM_PID, --父件编号
               T.ITEM_CID --子件编号
          FROM T_PARAM P
          JOIN T_LIST A
            ON 1 = 1
          JOIN EBOM_T_ENGSTRU T
            ON T.ITEM_PID = A.ITEM_ID --表示向下展开
           AND T.DATE_BGN <= P.QRY_DATE
           AND T.DATE_END > P.QRY_DATE

               T.ITEM_ID,
               null as RID,
               '0' as level_check,
               0 as LEV,
               '当前件' LEVEL_CHECK_DESC,
               T.NOT_FIT_C,
               T.NOT_FIT_P,
               T.NOT_FIT
          From T_RESULT_F T /*当前件*/
         Where T.NOT_FIT_C <= 0
           and T.NOT_FIT_P >= 0
        UNION ALL
        Select T.GROUP_ID, --组号
               null as ITEM_ID,
               T.ROWID_P1,
               '-1-1' as level_check,
               1,
               '1级父件',
               T.NOT_FIT_C,
               T.NOT_FIT_P,
               T.NOT_FIT
          From T_RESULT_F T /*1级父件*/
         Where T.NOT_FIT_C <= 1
           and T.NOT_FIT_P >= 1
           and T.ROWID_P1 IS NOT NULL
        UNION ALL
        Select T.GROUP_ID, --组号
               null as ITEM_ID,
               T.ROWID_P2,
               '-1-2' as level_check,
               2,
               '2级父件',
               T.NOT_FIT_C,
               T.NOT_FIT_P,
               T.NOT_FIT
          From T_RESULT_F T /*2级父件*/
         Where T.NOT_FIT_C <= 2
           and T.NOT_FIT_P >= 2
           and T.ROWID_P2 IS NOT NULL
        UNION ALL
        Select T.GROUP_ID, --组号
               null as ITEM_ID,
               T.ROWID_P3,
               '-1-3' as level_check,
               3,
               '3级父件',
               T.NOT_FIT_C,
               T.NOT_FIT_P,
               T.NOT_FIT
          From T_RESULT_F T /*3级父件*/
         Where T.NOT_FIT_C <= 3
           and T.NOT_FIT_P >= 3
           and T.ROWID_P3 IS NOT NULL
        UNION ALL
        Select T.GROUP_ID, --组号
               null as ITEM_ID,
               T.ROWID_P4,
               '-1-4' as level_check,
               4,
               '4级父件',
               T.NOT_FIT_C,
               T.NOT_FIT_P,
               T.NOT_FIT
          From T_RESULT_F T /*4级父件*/
         Where T.NOT_FIT_C <= 4
           and T.NOT_FIT_P >= 4
           and T.ROWID_P4 IS NOT NULL),
      T_RESULT_PR AS
       (select A.GROUP_ID, --组号
               A.LEVEL_CHECK_DESC, --级别
               CASE
                 WHEN A.LEV = 0 then
                  A.ITEM_ID
                 when A.LEV < 0 then
                  D.ITEM_CID
                 ELSE
                  U.ITEM_PID
               END as ITEM_ID_SHOW, --零件编号
               CASE
                 WHEN A.LEV = 0 then
                  A.ITEM_ID
                 when A.LEV < 0 then
                  D.ITEM_CID
                 ELSE
                  U.ITEM_CID
               END as ITEM_CID, --子件编号
               CASE
                 WHEN A.LEV = 0 then
                  A.ITEM_ID
                 when A.LEV < 0 then
                  D.ITEM_PID
                 ELSE
                  U.ITEM_PID
               END as ITEM_PID, --父件编号
               CASE
                 WHEN A.LEV = 0 then
                  C.VER_NUM
                 when A.LEV < 0 then
                  D.VER_NUM_C
                 ELSE
                  U.VER_NUM_P
               END as VER_NUM, --版本
               CASE
                 WHEN A.LEV = 0 then
                  C.ROUTE_MFGSTR_S
                 when A.LEV < 0 then
                  D.ROUTE_MFG_STR_S
                 ELSE
                  U.ROUTE_MFG_STR_S
               END as ROUTE_MFG_STR, /*当前制造路线*/
               CASE
                 WHEN A.LEV = 0 then
                  C.ROUTE_ASSEMSTR_S
                 when A.LEV < 0 then
                  D.ROUTE_ASSEM_STR_S
                 ELSE
                  U.ROUTE_ASSEM_STR_S
               END as ROUTE_ASSEM_STR, /*当前装配路线*/
               CASE
                 WHEN A.LEV = 0 then
                  C.ROUTE_MFGSTR
                 when A.LEV < 0 then
                  D.ROUTE_MFG_STR
                 ELSE
                  U.ROUTE_MFG_STR
               END as ROUTE_MFG_STR_C, /*计算时使用的*/
               CASE
                 WHEN A.LEV = 0 then
                  C.ROUTE_ASSEMSTR
                 when A.LEV < 0 then
                  D.ROUTE_ASSEM_STR
                 ELSE
                  U.ROUTE_ASSEM_STR
               END as ROUTE_ASSEM_STR_C, /*计算时使用的*/
               A.LEV,
               A.LEVEL_CHECK,
               A.NOT_FIT,
               A.NOT_FIT_C,
               A.NOT_FIT_P,
               A.RID
          from T_RESULT_R A
          left join T_LIST C /*当前件*/
            on A.ITEM_ID = C.ITEM_ID
           AND A.LEV = 0
          left join T_DOWN D /*向下*/
            ON A.RID = D.RID
           AND A.LEV < 0
          left join T_UP U /*向上*/
            ON A.RID = U.RID
           AND A.LEV > 0
         order by A.GROUP_ID, A.LEV)
      Select distinct TO_CHAR(A.GROUP_ID) AS GROUP_ID, --组号
                      A.ITEM_ID_SHOW AS ITEM_GROUP, --对比零件号
                      A.LEVEL_CHECK_DESC, --层级名称
                      TO_CHAR(A.LEV) AS ELEVEL, --层级数
                      A.NOT_FIT, --计算不符合标志
                      A.ROUTE_MFG_STR_C, /*计算时使用的制造路线*/
                      A.ROUTE_ASSEM_STR_C, /*计算时使用的装配路线*/
                      A.ROUTE_MFG_STR AS ROUTE_MFG_STR, --制造路线（编码）
                      A.ROUTE_ASSEM_STR AS ROUTE_ASSEM_STR, --装配路线（编码）
                      PKG_COM_UTIL.F_GETROUTELABELBYIDEXA(A.ROUTE_MFG_STR) AS ROUTE_MFG_DESC, --制造路线（名称）
                      PKG_COM_UTIL.F_GETROUTELABELBYIDEXA(A.ROUTE_ASSEM_STR) AS ROUTE_ASSEM_DESC, --装配路线（名称）
                      A.ROUTE_MFG_STR || '=' || A.ROUTE_ASSEM_STR AS ROUTE_GROUP, --路线组,格式:制造路线=装配路线
                      PKG_COM_UTIL.F_GETROUTELABELBYIDEXA(A.ROUTE_MFG_STR) || '=' ||
                      PKG_COM_UTIL.F_GETROUTELABELBYIDEXA(A.ROUTE_ASSEM_STR) AS ROUTE_GROUP_DESC, --路线组（名称）
                      A.ITEM_PID, -- 父件
                      A.ITEM_CID, -- 子件
                      NULL SEQ_ITEM_CID, -- 子女流水号
                      NULL LEVEL_PATH, -- 层代码
                      NULL LEVEL_PATH_PID, -- 父层代码
                      C.VER_NUM, --版本
                      A.LEVEL_CHECK, --级别：0：当前件；1：子件：2：父件
                      C.VER_NUM_ORIG, --系统版本
                      A.ITEM_ID_SHOW, --显示的零件号，取父件
                      C.ITEM_TYPE, --类型
                      C1.BIZ_DIC_NAME AS ITEM_TYPE_DESC, --类型（名称）
                      C.NAME_CHN, --零件名称
                      C.NAME_ENG, --英文名称
                      C.ITEM_STAGE, --生命周期状态
                      C2.BIZ_DIC_NAME AS ITEM_STAGE_DESC, --生命周期状态（名称）
                      C.PART_VER, --部件版本
                      C.PART_EDITION, --部件版次
                      C.DRAW_VER, --图档版本
                      C.DRAW_EDITION, --图档版次
                      P.CNCID AS CNC_ID, --计算的通知书号
                      P.MFG_CODE AS MFG_CENTER_CODE, --生产中心
                      P.CONVERSATIONID AS CONVERSATIONID --业务会话ID
        from T_RESULT_PR A
        join T_PARAM P
          ON 1 = 1
        Left Join EBOM_T_ITMENGC C
          On A.ITEM_ID_SHOW = C.ITEM_ID
         And A.VER_NUM = C.VER_NUM
        Left Join Dp_Sys_t_Busidic C1
          On C.ITEM_TYPE = C1.BIZ_DIC_CODE
        Left Join Dp_Sys_t_Busidic C2
          On C.ITEM_STAGE = C2.BIZ_DIC_CONTENT
         And C2.BIZ_DIC_PCODE = 'dt_Maturity'
        Left Join Dp_Sys_t_Busidic C3
          On C.MEASURE_UNIT = C3.BIZ_DIC_CODE
        Left Join Dp_Sys_t_Busidic C4
          On C.SAFECODE = C4.BIZ_DIC_CODE
       order by A.GROUP_ID, A.LEV desc;

    --2、查询柳柳分析结果：【柳柳分析起点】
    Open o_ResData_ll_cur FOR
      WITH T_IN_PARA AS /*【输入参数】原始*/
       (SELECT i_cncid as CNCID, /*PDM变更单号：i_cncid*/
               i_mfgcentercode AS MFG_CODE, /*工厂ID：i_mfgcentercode*/
               i_ItemIDVer as ITEM_ID_VER, /*展开项目ID：i_ItemIDVer，（支持逗号分隔多个，每个零件以分号分隔）*/
               v_ConversationId AS CONVERSATIONID, /*会话ID*/
               v_QueryDate AS QRY_DATE, /*查询日期*/
               v_OperatorId as OPERATOR_ID, /*操作人*/
               '99999999' AS MAX_DATE_END
          FROM DUAL),
      T_PARAM AS /*【输入参数】增加计算类型*/
       (select A.*,
               CASE
                 WHEN A.ITEM_ID_VER IS NOT NULL THEN
                  '3'
                 WHEN A.CNCID LIKE 'PCO%' THEN
                  '1'
                 ELSE
                  '2'
               END CAL_TYPE /*计算类型：1-PCO，2-PDM，3-按零件计算*/
          from T_IN_PARA A),
      T_ITM_LI_IN AS /*【零件版本】入参*/
       (Select substr(column_value, 0, instr(column_value, ';') - 1) as ITEM_ID,
               substr(column_value, instr(column_value, ';') + 1) AS VER_NUM
          From Table(pkg_com_util.F_GetStrConvertCol((select ITEM_ID_VER
                                                       from T_IN_PARA),
                                                     ','))),
      T_ROUTE AS /*【零件路线表】传入工厂的零件版本只取最新那一条记录*/
       (select AA.*
          FROM (SELECT T.MFG_CENTER_CODE,
                       T.ITEM_ID,
                       T.VER_NUM,
                       T.CNC_EDIT,
                       CASE
                         WHEN W.ITEM_ID IS NULL THEN
                          T.ROUTE_MFGSTR
                         ELSE
                          NULL
                       END AS ROUTE_MFGSTR, /*制造路线：无路线表存在时取空，用于后面的判断*/
                       CASE
                         WHEN W.ITEM_ID IS NULL THEN
                          T.ROUTE_ASSEMSTR
                         ELSE
                          NULL
                       END AS ROUTE_ASSEMSTR, /*装配路线：无路线表存在时取空，用于后面的判断*/
                       CASE
                         WHEN W.ITEM_ID IS NULL THEN
                          0
                         ELSE
                          1
                       END AS NOROUT_T, /*无路线标识：0-否，1-是*/
                       ROW_NUMBER() over (PARTITION BY T.ITEM_ID, T.VER_NUM order by T.CREATE_TIME desc) as RNUM /*按零件号和版本分组，按创建时间倒序排列取第一个*/
                  FROM MBOM_T_QDITMROUTE_HIS T /*路线变更表*/
                  JOIN T_PARAM P /*参数*/
                    ON T.MFG_CENTER_CODE = P.MFG_CODE
                  left join MBOM_T_QDROUTMFGITM W /*无路线表*/
                    on W.MFG_CENTER_CODE = T.MFG_CENTER_CODE
                   And W.ITEM_ID = T.ITEM_ID
                   And W.VER_NUM = T.VER_NUM) AA
         where AA.RNUM = 1),
      T_ITM_LI AS /*【零件版本】计算清单：注要包括无须配置路线表的*/
       (Select A.ITEM_ID, --零件号
               A.VER_NUM --版本
          From T_ITM_LI_IN A
          JOIN T_PARAM P
            on P.CAL_TYPE = '3'
         where exists (select 1 --存在于MBOM表的
                  from MBOM_T_MFGITM M
                 where M.MFG_CENTER_CODE = P.MFG_CODE
                   AND M.ITEM_ID = A.ITEM_ID
                   AND M.VER_NUM = A.VER_NUM)),
      T_PCO_LI as /*【PCO】零件列表：跳过无制造路线的，注要包括无须配置路线表的*/
       (Select h.ITEM_ID, --零件号
               h.VER_NUM --版本
          From mbom_t_qditmroute_his h /*路线变更表：这里还是使用最原始的路线变更表*/
          join T_PARAM P
            on P.CAL_TYPE = '1'
           and H.MFG_CENTER_CODE = P.MFG_CODE
          Join ebom_t_itmengc t
            On h.item_id = t.item_id
           And h.ver_num = t.ver_num
         Where h.cnc_edit = P.CNCID
           And h.ROUTE_MFGSTR Is Not Null),
      T_PDM_LI As /*【PDM】零件列表：注要包括无须配置路线表的*/
       (Select A.ITEM_ID, --零件号
               N.VER_NUM, --版本
               P.MFG_CODE,
               P.QRY_DATE
          From EBOM_T_CNCQ_ITEM A
          Join EBOM_T_ITMENGC N
            On A.ITEM_ID = N.ITEM_ID
           And A.VER_NUM_ORIG = N.VER_NUM_ORIG
          JOIN T_PARAM P
            on P.CAL_TYPE = '2'
         Where A.CNC_ID = P.CNCID
           and exists (select 1 --存在于MBOM表的
                  from MBOM_T_MFGITM M
                 where M.MFG_CENTER_CODE = P.MFG_CODE
                   and M.ITEM_ID = A.ITEM_ID
                   AND M.VER_NUM = N.VER_NUM)),
      T_FN_LI as /*【最终的零件列表】*/
       (Select A.ITEM_ID, A.VER_NUM
          From T_PDM_LI A
        union all
        Select A.ITEM_ID, A.VER_NUM
          From T_PCO_LI A
        union all
        Select A.ITEM_ID, A.VER_NUM
          From T_ITM_LI A),
      T_LIST AS /*【最终计算的零件范围】都是有制造路线的。路线取最新的，不排除柳柳件*/
       (SELECT sys_guid() as ITEM_TEMP_ID,
               A.ITEM_ID,
               A.VER_NUM,
               R1.NOROUT_T, --无须路线标志
               PKG_JF_QD_PARENT_CHILD_COMP.F_GET_ROUTEMFG_STR(R1.route_mfgstr) as ROUTE_MFGSTR,
               PKG_JF_QD_PARENT_CHILD_COMP.F_GET_ROUTEMFG_STR(R1.Route_Assemstr) as ROUTE_ASSEMSTR,
               R1.route_mfgstr as ROUTE_MFGSTR_S, /*原制造路线编码*/
               R1.Route_Assemstr as ROUTE_ASSEMSTR_S /*原装配路线编码*/
          FROM T_FN_LI A
          JOIN T_PARAM P
            ON 1 = 1
          LEFT JOIN T_ROUTE R1 /*路线变更临时表*/
            ON R1.MFG_CENTER_CODE = P.MFG_CODE
           AND R1.ITEM_ID = A.ITEM_ID
           AND R1.VER_NUM = A.VER_NUM),
      T_DOWN_ALL as /*所有层级的子件：注这里跟父子一致性比较不一样*/
       (Select w.ITEM_CID, W.ITEM_PID, Level As LVL, W.ROWID AS RID
          From (Select AA.ITEM_CID, AA.ITEM_PID
                  From ebom_t_engstru AA
                 Where AA.date_end = '99999999'
                   and EXISTS (SELECT 1 /*子件存在于MBOM表*/
                          FROM MBOM_T_MFGITM M
                         WHERE M.MFG_CENTER_CODE =
                               (SELECT P.MFG_CODE FROM T_PARAM P)
                           AND M.ITEM_ID = AA.ITEM_CID)) W
         Start With w.item_pid in (select L.ITEM_ID from T_LIST L) --从零件清单开始
        Connect By w.item_pid = Prior w.item_cid),
      T_ALL AS /*当前件和子件*/
       (SELECT A.ROUTE_MFGSTR AS ROUTE_MFG_STR,
               A.ROUTE_ASSEMSTR AS ROUTE_ASSEM_STR,
               '' as ITEM_PID,
               A.ITEM_ID as ITEM_CID,
               A.VER_NUM as VER_NUM
          FROM T_LIST A /*子件*/
        union /*子件*/
        SELECT PKG_JF_QD_PARENT_CHILD_COMP.F_GET_ROUTEMFG_STR(R1.ROUTE_MFGSTR) AS ROUTE_MFG_STR,
               PKG_JF_QD_PARENT_CHILD_COMP.F_GET_ROUTEMFG_STR(R1.ROUTE_ASSEMSTR) AS ROUTE_ASSEM_STR,
               A.ITEM_PID,
               A.ITEM_CID,
               CT.VER_NUM as VER_NUM
          FROM T_DOWN_ALL A /*子件*/
          JOIN T_PARAM P /*参数*/
            ON 1 = 1
          join EBOM_T_ITMENGC CT /*取子件版本：根据8个9获取？？*/
            on A.ITEM_CID = CT.ITEM_ID
           and CT.DATE_END = P.MAX_DATE_END
          LEFT JOIN T_ROUTE R1 /*工艺路线变更*/
            ON R1.ITEM_ID = A.ITEM_CID
           AND R1.MFG_CENTER_CODE = P.MFG_CODE
           AND R1.VER_NUM = CT.VER_NUM),
      T_RESULT as /*比较结果:当前工厂标识为青或青柳，但制造路线=柳*/
       (Select P.ConversationId As CONVERSATIONID, --业务会话id
               P.MFG_CODE As MFG_CENTER_CODE, --生产中心
               t1.item_cid As item_id, --零件号
               t1.ver_num As ver_num, --版本
               t1.route_mfg_str, --制造路线（编码）
               t1.route_assem_str, --装配路线（编码）
               null remark, --备注
               case (Select b.qd_factory_flag
                   From (Select a.*,
                                row_number() over (Partition By a.item_id Order By a.his_seq Desc) rn
                           From mbom_t_qditmprop_his a) b
                  Where rn = 2
                    And b.item_id = PR.item_id)
                 when 'dt_qd_mfgFlag_01' then
                  '青'
                 when 'dt_qd_mfgFlag_02' then
                  '柳'
                 when 'dt_qd_mfgFlag_03' then
                  '青柳'
                 else
                  null
               end As factory_tag_old, --旧工厂标识
               case PR.qd_factory_flag
                 when 'dt_qd_mfgFlag_01' then
                  '青'
                 when 'dt_qd_mfgFlag_03' then
                  '青柳'
               end As factory_tag_new --新工厂标识
          From T_ALL t1
          join T_PARAM P
            on 1 = 1
          Join mbom_t_qditmprop PR
            on T1.item_cid = PR.ITEM_ID
           and PR.qd_factory_flag IN
               ('dt_qd_mfgFlag_01', 'dt_qd_mfgFlag_03') --工厂标识为青或青柳
         where t1.route_mfg_str = 'Q31' --制造路线为柳Q31
           and exists (Select 1
                  From (Select a.*,
                               row_number() over (Partition By a.item_id Order By a.his_seq Desc) rn
                          From mbom_t_qditmprop_his a) b
                 Where rn = 2
                   And (b.qd_factory_flag = 'dt_qd_mfgFlag_02' OR
                       b.qd_factory_flag is null) --上一版为空或柳
                   And b.item_id = PR.item_id))
      Select A.ITEM_ID AS ITEM_ID_, --零件号
             A.VER_NUM AS VER_NUM_, --版本
             C.ITEM_TYPE AS ITEM_TYPE_, --类型
             C1.BIZ_DIC_NAME AS ITEM_TYPE_DESC_, --类型（名称）
             C.NAME_CHN AS NAME_CHN_, --零件名称
             C.NAME_ENG AS NAME_ENG_, --英文名称
             C.ITEM_STAGE AS ITEM_STAGE_, --生命周期状态
             C2.BIZ_DIC_NAME AS ITEM_STAGE_DESC_, --生命周期状态（名称）
             C.PART_VER AS PART_VER_, --部件版本
             C.PART_EDITION AS PART_EDITION_, --部件版次
             C.DRAW_VER AS DRAW_VER_, --图档版本
             C.DRAW_EDITION AS DRAW_EDITION_, --图档版次
             A.ROUTE_MFG_STR AS ROUTE_MFG_STR_, --制造路线（编码）
             PKG_COM_UTIL.F_GETROUTELABELBYIDEXA(A.ROUTE_MFG_STR) AS ROUTE_MFG_DESC_, --制造路线（名称）
             A.ROUTE_ASSEM_STR AS ROUTE_ASSEM_STR_, --装配路线（编码）
             PKG_COM_UTIL.F_GETROUTELABELBYIDEXA(A.ROUTE_ASSEM_STR) AS ROUTE_ASSEM_DESC_, --装配路线（名称）
             A.ROUTE_MFG_STR || '=' || A.ROUTE_ASSEM_STR AS ROUTE_GROUP_, --路线组,格式:制造路线=装配路线
             PKG_COM_UTIL.F_GETROUTELABELBYIDEXA(A.ROUTE_MFG_STR) || '=' ||
             PKG_COM_UTIL.F_GETROUTELABELBYIDEXA(A.ROUTE_ASSEM_STR) AS ROUTE_GROUP_DESC_, --路线组（名称）
             NULL AS REMARK_, --备注
             A.FACTORY_TAG_OLD, --旧工厂标识
             A.FACTORY_TAG_NEW, --新工厂标识
             C.VER_NUM_ORIG as VER_NUM_ORIG_,
             P.CNCID AS CNC_ID_, --计算的通知书号
             P.MFG_CODE AS MFG_CENTER_CODE_, --生产中心
             P.CONVERSATIONID AS CONVERSATIONID_ --业务会话ID
        from T_RESULT A
        join T_PARAM P
          ON 1 = 1
        Left Join Ebom_t_Itmengc C
          On A.VER_NUM = C.VER_NUM
         And A.item_id = C.ITEM_ID
        Left Join Dp_Sys_t_Busidic C1
          On C.ITEM_TYPE = C1.BIZ_DIC_CODE
        Left Join Dp_Sys_t_Busidic C2
          On C.ITEM_STAGE = C2.BIZ_DIC_CONTENT
         And C2.BIZ_DIC_PCODE = 'dt_Maturity';
  --返回成功
    o_Return_Code := pkg_com_define.const_ok;
  Exception
    When Others Then
      o_Return_Code := Pkg_Com_Define.Const_Error;
      o_Sqlerrm     := Sqlerrm;
  END;

END PKG_JF_QD_PARENT_CHILD_COMP;
