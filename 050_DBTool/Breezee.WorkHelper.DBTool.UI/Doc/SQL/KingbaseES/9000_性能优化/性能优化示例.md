## 性能优化示例
### 使用 plsql_plprofiler 插件
```
1. 创建插件（通常只需执行一次）：						
	CREATE EXTENSION plsql_plprofiler;					
2. 准备测试：确保你的包（Package）和其中的存储过程已正确创建。						
3. 开启分析并执行（注：要一步步执行，不能同时执行）：						
	-- 1. 清理本地和全局的旧数据，确保结果准确					
	SELECT pl_profiler_reset_local();					
	SELECT pl_profiler_reset_shared();					
						
	-- 2. 启动当前会话的分析器					
	SELECT pl_profiler_set_enabled_local(true);					
						
	-- 3. 执行你想要测试的包中的存储过程					
	-- 假设你的包名为 my_package，过程名为 test_proc					
	CALL my_package.test_proc();					
						
	-- 4. 关闭分析器					
	SELECT pl_profiler_set_enabled_local(false);					
						
	-- 5. 收集数据					
	SELECT pl_profiler_collect_data();					
4. 查看分析结果：						
运行以下查询，你将得到一张详细的报告，包含每一行代码的执行统计。						
	SELECT 					
	    L.func_oid::regproc AS funcname,					
	    L.line_number,					
	    SUM(L.exec_count)::bigint AS exec_count,					
	    SUM(L.total_time)::bigint AS total_time,  -- 总时间（微秒）					
	    MAX(L.longest_time)::bigint AS longest_time, -- 单次最长执行时间（微秒）					
	    S.source					
	FROM pl_profiler_linestats_shared() L					
	JOIN pl_profiler_funcs_source(pl_profiler_func_oids_shared()) S 					
	    ON S.func_oid = L.func_oid AND S.line_number = L.line_number					
	GROUP BY  L.func_oid, L.line_number, S.source					
	ORDER BY L.func_oid, L.line_number;					
						
	注意：total_time 和 longest_time 的单位是微秒
```
